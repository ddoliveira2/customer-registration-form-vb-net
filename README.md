# customer-registration-form-vb-net

Aplicação desktop Windows Forms desenvolvida em VB.NET para criação, consulta e gerenciamento de cadastros de clientes.

## Sobre o Projeto

Aplicação desktop Windows Forms desenvolvida em VB.NET para criação, consulta e gerenciamento de cadastros de clientes.

## Tecnologias Utilizadas

- VB.NET
- .NET Framework / Windows Forms
- Controles Windows Forms
- SQL Server

## Funcionalidades

- Formulário para inclusão de clientes
- Listagem de registros em DataGridView
- Filtros para busca rápida
- Interação com controles e eventos da interface

## Arquitetura do Projeto

Arquitetura orientada a eventos (Event-Driven), utilizando formulários e controles Windows Forms. Os eventos da interface acionam as operações correspondentes da aplicação.

## Banco de Dados

SQL Server

## Aprendizados

- Desenvolvimento desktop com VB.NET.
- Construção de interfaces Windows Forms.
- Manipulação de eventos e controles.
- Exibição e filtragem de dados em DataGridView.
